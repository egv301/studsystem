# Spring boot application for student management system 
Single page application for student management system app using spring boot and jquery
App represents system with two roles: Teachers and Admin

Admin can:
- Add/Edit/Remove Groups
- Add/Edit/Remove Students
- Add/Edit/Remove Subjects
  
Teachers can:
- Add/Edit/Remove Subject assignments
- Put marks for assignments
- Taking student attendance

### Technologies: 
- Spring boot
- Spring Data Jpa
- Spring Validaion Api
- Jquery on frontend
- Sprint secutiry role based authentication using JWT token
